# Фотографии и файл автозагрузки для Авито — ООО ЛОФТ

Репозиторий обслуживает автозагрузку объявлений на Авито.

- `avito.xml` — файл автозагрузки, ссылка указывается в кабинете Авито
- `foto/` — снимки объявлений, по папке на объявление

Файл `avito.xml` пересобирается скриптом `avito_xml.py` из рабочей таблицы.
Правки вносятся в таблицу, а не здесь.
